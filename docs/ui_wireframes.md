# UI Wireframes

## Page 1 — Landing / Login
Two tabs: Sign In / Register. Email + password. 

## Page 2 — Dashboard
Overview cards (Reports, Active Research, Watchlist, Significant Events).
Activity chart. Recent research table. Quick actions.

## Page 3 — New Research
Form (company, industry, known competitors, depth). Agent preview sidebar.

## Page 4 — Research Progress
Progress bar. Agent log stream. "View Report" button when complete.

## Page 5 — Report Viewer
Executive summary → confidence gauge → competitive landscape → SWOT grid → timeline → trends → recommendations → export.

## Page 6 — Competitor Detail
Deep-dive view with metadata.

## Page 7 — Reports Library
Searchable list of all past reports.

## Page 8 — Watchlist
Table of watched companies with frequency toggles.

## Page 9 — Intelligence Feed
Filterable event feed with significance badges.

## Page 10 — Settings
Account, API keys, notifications.
